No curve here — a trace is a path along the mesh edges. Finer grid packs more vertical & horizontal lines and more path vertices, so it looks smooth like pixels — but the denser grid is there so you never forget it's an illusion. Layer separation spreads the shells apart on the C60 and splits the flat view into one plane per layer (like any PCB tool) — slide to 0 to collapse them back into one. And the flat plane is fully designable: Place / Wire / Erase work here too, on whichever layer plane you click. Yet it's always the 3D mesh — the 12 gold pentagons ride every plane as the volumetric constraints. Grid level is the LOD you pay for.
